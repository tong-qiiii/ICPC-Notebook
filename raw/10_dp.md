## 10.1 0/1、完全、多重、分组背包

> **用途**：容量型背包的四个常用版本，求不超过容量 `C` 时的最大价值。
> **复杂度**：0/1、完全 `O(nC)`；多重 `O(C \sum \log(c_i+1))`；分组 `O(C \sum |G_i|)`；空间均为 `O(C)`
> **下标**：物品 `1 ~ n`，容量 `0 ~ C`
> **限制**：物品重量 `w > 0`
> **注意**：默认“不超过容量”且允许不选；恰好装满时 `dp[1..C] = -INF`。

### 0/1 背包

```cpp
vector<ll> dp(C + 1);

for (int i = 1; i <= n; ++i) {
    int w;
    ll v;
    cin >> w >> v;

    for (int j = C; j >= w; --j)
        dp[j] = max(dp[j], dp[j - w] + v);
}

cout << dp[C] << '\n';
```

### 完全背包

```cpp
vector<ll> dp(C + 1);

for (int i = 1; i <= n; ++i) {
    int w;
    ll v;
    cin >> w >> v;

    for (int j = w; j <= C; ++j)
        dp[j] = max(dp[j], dp[j - w] + v);
}

cout << dp[C] << '\n';
```

### 多重背包（二进制拆分）

```cpp
vector<ll> dp(C + 1);

for (int i = 1; i <= n; ++i) {
    int w, c;
    ll v;
    cin >> w >> v >> c;

    for (int k = 1; c > 0; k <<= 1) {
        int take = min(k, c);
        int ww = w * take;
        ll vv = v * take;
        c -= take;

        for (int j = C; j >= ww; --j)
            dp[j] = max(dp[j], dp[j - ww] + vv);
    }
}

cout << dp[C] << '\n';
```

### 分组背包

```cpp
vector<ll> dp(C + 1);

for (int i = 1; i <= n; ++i) {
    int cnt;
    cin >> cnt;

    vector<pair<int, ll>> group(cnt);
    for (auto& [w, v] : group) cin >> w >> v;

    for (int j = C; j >= 0; --j)
        for (auto [w, v] : group)
            if (j >= w)
                dp[j] = max(dp[j], dp[j - w] + v);
}

cout << dp[C] << '\n';
```

### 现场记忆

```text
0/1：容量倒序
完全：容量正序
多重：二进制拆成若干个 0/1 物品
分组：容量倒序，同组物品都从较小容量的旧状态转移

恰好装满：dp[0] = 0，其余 = -INF
```

## 10.2 区间 DP（石子合并骨架）

> **用途**：处理“将区间切成左右两部分再合并”的区间 DP；代码对应经典连续石子合并最小代价。
> **复杂度**：时间 `O(n^3)`，空间 `O(n^2)`
> **下标**：`1-indexed`

```cpp
const ll INF = LLONG_MAX / 4;

vector<ll> a(n + 1), pre(n + 1);
vector<vector<ll>> dp(n + 1, vector<ll>(n + 1, INF));

for (int i = 1; i <= n; ++i) {
    cin >> a[i];
    pre[i] = pre[i - 1] + a[i];
    dp[i][i] = 0;
}

for (int len = 2; len <= n; ++len) {
    for (int l = 1; l + len - 1 <= n; ++l) {
        int r = l + len - 1;
        ll sum = pre[r] - pre[l - 1];

        for (int k = l; k < r; ++k)
            dp[l][r] = min(dp[l][r],
                           dp[l][k] + dp[k + 1][r] + sum);
    }
}

cout << dp[1][n] << '\n';
```

### 现场记忆

```text
枚举顺序：区间长度 -> 左端点 -> 断点 k
dp[l][r] = min(dp[l][k] + dp[k+1][r] + merge_cost)
初始化 dp[i][i] = 0
```

## 10.3 树形 DP（最大权独立集骨架）

> **用途**：树上父子状态合并；代码对应“相邻点不能同时选择”的最大权独立集，也是常用 `dp[u][0/1]` 骨架。
> **复杂度**：时间 `O(n)`，空间 `O(n)`
> **下标**：节点 `1 ~ n`
> **注意**：链状树较深时递归可能爆栈。

```cpp
vector<vector<int>> g(n + 1);
vector<ll> w(n + 1);
vector<array<ll, 2>> dp(n + 1);

for (int u = 1; u <= n; ++u) cin >> w[u];

for (int i = 1; i < n; ++i) {
    int u, v;
    cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u);
}

auto dfs = [&](auto&& self, int u, int fa) -> void {
    dp[u][0] = 0;
    dp[u][1] = w[u];

    for (int v : g[u]) {
        if (v == fa) continue;
        self(self, v, u);

        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
    }
};

dfs(dfs, 1, 0);
cout << max(dp[1][0], dp[1][1]) << '\n';
```

### 现场记忆

```text
dp[u][0]：不选 u
dp[u][1]：选 u

不选 u：dp[u][0] += max(dp[v][0], dp[v][1])
选 u：  dp[u][1] += dp[v][0]
```

## 10.4 换根 DP（全点距离和）

> **用途**：求树上每个点到所有点的距离和；无权树和加权树均可使用。
> **复杂度**：时间 `O(n)`，空间 `O(n)`
> **下标**：节点 `1 ~ n`
> **注意**：`siz[u]` 为子树节点数；链状树较深时递归可能爆栈。

```cpp
vector<vector<pair<int, ll>>> g(n + 1);
vector<int> siz(n + 1);
vector<ll> down(n + 1), ans(n + 1);

for (int i = 1; i < n; ++i) {
    int u, v;
    ll w;
    cin >> u >> v >> w;

    g[u].push_back({v, w});
    g[v].push_back({u, w});
}

auto dfs1 = [&](auto&& self, int u, int fa) -> void {
    siz[u] = 1;

    for (auto [v, w] : g[u]) {
        if (v == fa) continue;
        self(self, v, u);

        siz[u] += siz[v];
        down[u] += down[v] + 1LL * siz[v] * w;
    }
};

auto dfs2 = [&](auto&& self, int u, int fa) -> void {
    for (auto [v, w] : g[u]) {
        if (v == fa) continue;

        ans[v] = ans[u] + 1LL * (n - 2 * siz[v]) * w;
        self(self, v, u);
    }
};

dfs1(dfs1, 1, 0);
ans[1] = down[1];
dfs2(dfs2, 1, 0);

for (int u = 1; u <= n; ++u) cout << ans[u] << '\n';
```

### 现场记忆

```text
第一次 DFS：
down[u] += down[v] + siz[v] * w

u -> 儿子 v 换根：
v 子树 siz[v] 个点距离减少 w
其余 n-siz[v] 个点距离增加 w

ans[v] = ans[u] + (n - 2*siz[v]) * w
```

## 10.5 数位 DP（记忆化通用骨架）

> **用途**：统计 `[0, x]` 中满足数位限制的整数个数，区间询问用前缀差。
>
> **复杂度**：时间 `O(D * S * 10)`，空间 `O(D * S)`，`D <= 19`
>
> **下标**：数位 `0-indexed`
>
> **注意**：
> - 按题主要修改：`S`、终止条件、状态转移。
> - 默认前导 `0` 可直接参与转移；若首位、相邻位等受前导零影响，再加 `started`。
> - 只记忆化 `lim = false` 的状态。

### 调用

```cpp
cout << query(l, r) << '\n';
```

### 模板

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

const int S = 1; // 状态数，按题修改

vector<int> dig;
ll memo[20][S][2];

ll dfs(int pos, int st, bool lim, bool started)
{
    if (pos == (int)dig.size())
    {
        return started && /* st 合法 */;
    }

    if (!lim && memo[pos][st][started] != -1)
        return memo[pos][st][started];

    int up = lim ? dig[pos] : 9;
    ll res = 0;

    for (int d = 0; d <= up; ++d)
    {
        bool nlim = lim && d == dig[pos];

        if (!started && d == 0)
        {
            res += dfs(pos + 1, st, nlim, false);
            continue;
        }

        int ns = st; // 按题修改

        res += dfs(pos + 1, ns, nlim, true);
    }

    if (!lim)
        memo[pos][st][started] = res;

    return res;
}

ll calc(ll x) {
    if (x < 0) return 0;

    dig.clear();
    for (char c : to_string(x))
        dig.push_back(c - '0');

    memset(memo, -1, sizeof(memo));

    return dfs(0, 0, true, false);
}

ll query(ll l, ll r) {
    if (l > r) return 0;
    return calc(r) - calc(l - 1);
}
```

### 现场记忆

```text
dfs(pos, st, lim)：处理到 pos，当前状态 st，前缀是否贴着上界
up = lim ? dig[pos] : 9
nlim = lim && (d == dig[pos])

按题只想三件事：
1. st 记录什么
2. 放入 d 后 st 怎么转移
3. pos == n 时哪些状态合法

区间答案 = calc(r) - calc(l - 1)
前导零影响状态时，再加 started
```


## 10.6 状压 DP（Hamilton 路径 / TSP 骨架）

> **用途**：小规模点集上枚举已选集合；代码求从 `s` 出发、经过所有点、最终到 `t` 的最短 Hamilton 路径。
> **复杂度**：时间 `O(n^2 2^n)`，空间 `O(n 2^n)`
> **下标**：节点 `0 ~ n-1`
> **限制**：通常 `n <= 20`

```cpp
const ll INF = LLONG_MAX / 4;

vector<vector<ll>> w(n, vector<ll>(n));
for (int i = 0; i < n; ++i)
    for (int j = 0; j < n; ++j)
        cin >> w[i][j];

int s = 0, t = n - 1;
int S = 1 << n;

vector<vector<ll>> dp(S, vector<ll>(n, INF));
dp[1 << s][s] = 0;

for (int mask = 0; mask < S; ++mask) {
    for (int u = 0; u < n; ++u) {
        if (!(mask >> u & 1) || dp[mask][u] == INF) continue;

        for (int v = 0; v < n; ++v) {
            if (mask >> v & 1) continue;
            if (w[u][v] >= INF / 2) continue;

            int nmask = mask | (1 << v);
            dp[nmask][v] = min(dp[nmask][v],
                               dp[mask][u] + w[u][v]);
        }
    }
}

cout << dp[S - 1][t] << '\n';
```

### 现场记忆

```text
dp[mask][u] = 已访问 mask，当前停在 u 的最优值
mask,u -> mask|(1<<v),v

Hamilton 路径：dp[full][t]
TSP 回到起点：枚举终点 u，再加 w[u][s]
```

## 10.7 轮廓线 DP（多米诺骨牌铺满）

> **用途**：网格按行推进，只保留当前轮廓状态；代码统计带障碍网格的 `1×2` 多米诺骨牌铺满方案数。
> **复杂度**：时间最坏 `O(n 3^m)`，空间 `O(2^m)`，代码自动令 `m` 为较短边。
> **下标**：网格 `0-indexed`
> **限制**：`'#'` 为障碍，其余位置可放置骨牌。
> **注意**：方案数可能超过 `long long`，需要取模时修改累加位置。

### 调用

```cpp
vector<string> a(n);

for (auto& s : a) cin >> s;

cout << dominoTilings(a) << '\n';
```

### 模板

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

ll dominoTilings(vector<string> a) {
    if (a.empty() || a[0].empty()) return 1;

    int n = a.size();
    int m = a[0].size();

    if (m > n) {
        vector<string> b(m, string(n, '.'));

        for (int i = 0; i < n; ++i)
            for (int j = 0; j < m; ++j)
                b[j][i] = a[i][j];

        a.swap(b);
        swap(n, m);
    }

    vector<int> block(n);

    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j)
            if (a[i][j] == '#') block[i] |= 1 << j;

    int S = 1 << m;
    vector<ll> dp(S), ndp(S);
    dp[0] = 1;

    function<void(int, int, int, int, ll)> dfs = [&](int row, int col, int occ, int nxt, ll ways) {
        if (col == m) {
            ndp[nxt] += ways;
            return;
        }

        if (occ >> col & 1) {
            dfs(row, col + 1, occ, nxt, ways);
            return;
        }

        if (col + 1 < m && !(occ >> (col + 1) & 1))
            dfs(row, col + 2, occ, nxt, ways);

        if (row + 1 < n && !(block[row + 1] >> col & 1))
            dfs(row, col + 1, occ, nxt | (1 << col), ways);
    };

    for (int row = 0; row < n; ++row) {
        fill(ndp.begin(), ndp.end(), 0);

        for (int mask = 0; mask < S; ++mask) {
            if (!dp[mask] || (mask & block[row])) continue;
            dfs(row, 0, mask | block[row], 0, dp[mask]);
        }

        dp.swap(ndp);
    }

    return dp[0];
}
```

### 现场记忆

```text
mask：本行已被上一行竖骨牌占掉的位置
nxt：本行向下一行伸出的竖骨牌

当前位置空：
横放 -> 一次吃掉两列
竖放 -> nxt 对应位设 1

一行结束 dp = ndp
最终必须回到 mask = 0
```

## 10.8 插头 DP（网格 Hamilton 单回路）

> **用途**：统计带障碍网格中经过所有可走格恰好一次的 Hamilton 回路；标准括号插头 DP。
> **复杂度**：设可达插头状态数为 `S`，时间最坏 `O(nm^2S)`，空间 `O(S)`
> **下标**：网格 `0-indexed`
> **限制**：`'#'` 为障碍；状态使用 64 位编码，较短边需 `<= 31`，实际通常只适合约 `12 ~ 15`。
> **注意**：代码自动令较短边为状态宽度；答案可能溢出 `long long`。

### 调用

```cpp
vector<string> a(n);

for (auto& s : a) cin >> s;

cout << plugHamiltonCycle(a) << '\n';
```

### 模板

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;
using ull = unsigned long long;

int plugGet(ull s, int p) {
    return (s >> (p * 2)) & 3ULL;
}

ull plugSet(ull s, int p, int v) {
    ull mask = 3ULL << (p * 2);
    return (s & ~mask) | (ull(v) << (p * 2));
}

void addState(unordered_map<ull, ll>& mp, ull s, ll v) {
    mp[s] += v;
}

ll plugHamiltonCycle(vector<string> a) {
    if (a.empty() || a[0].empty()) return 0;

    int n = a.size();
    int m = a[0].size();

    if (m > n) {
        vector<string> b(m, string(n, '.'));

        for (int i = 0; i < n; ++i)
            for (int j = 0; j < m; ++j)
                b[j][i] = a[i][j];

        a.swap(b);
        swap(n, m);
    }

    int lastFree = -1;

    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j)
            if (a[i][j] != '#') lastFree = i * m + j;

    if (lastFree == -1) return 0;

    unordered_map<ull, ll> dp, ndp;
    dp.reserve(1 << min(m, 16));
    dp[0] = 1;

    ll ans = 0;

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            ndp.clear();
            ndp.reserve(dp.size() * 2 + 16);

            bool freeCell = a[i][j] != '#';
            bool down = i + 1 < n && a[i + 1][j] != '#';
            bool right = j + 1 < m && a[i][j + 1] != '#';

            for (auto [s, ways] : dp) {
                int L = plugGet(s, j);
                int U = plugGet(s, j + 1);

                ull base = plugSet(plugSet(s, j, 0), j + 1, 0);

                if (!freeCell) {
                    if (L == 0 && U == 0) addState(ndp, base, ways);
                    continue;
                }

                if (L == 0 && U == 0) {
                    if (down && right) {
                        ull ns = plugSet(plugSet(base, j, 1), j + 1, 2);
                        addState(ndp, ns, ways);
                    }
                    continue;
                }

                if ((L == 0) ^ (U == 0)) {
                    int p = L ? L : U;
                    if (down) addState(ndp, plugSet(base, j, p), ways);
                    if (right) addState(ndp, plugSet(base, j + 1, p), ways);
                    continue;
                }

                if (L == 1 && U == 1) {
                    int bal = 1;

                    for (int k = j + 2; k <= m; ++k) {
                        int x = plugGet(s, k);
                        if (x == 1) ++bal;
                        if (x == 2) --bal;

                        if (bal == 0) {
                            addState(ndp, plugSet(base, k, 1), ways);
                            break;
                        }
                    }
                } else if (L == 2 && U == 2) {
                    int bal = 1;

                    for (int k = j - 1; k >= 0; --k) {
                        int x = plugGet(s, k);
                        if (x == 2) ++bal;
                        if (x == 1) --bal;

                        if (bal == 0) {
                            addState(ndp, plugSet(base, k, 2), ways);
                            break;
                        }
                    }
                } else if (L == 2 && U == 1) {
                    addState(ndp, base, ways);
                } else if (L == 1 && U == 2) {
                    if (base == 0 && i * m + j == lastFree) ans += ways;
                }
            }

            dp.swap(ndp);
        }

        if (i + 1 < n) {
            unordered_map<ull, ll> shifted;
            shifted.reserve(dp.size() * 2 + 16);

            for (auto [s, ways] : dp) addState(shifted, s << 2, ways);

            dp.swap(shifted);
        }
    }

    return ans;
}
```

### 现场记忆

```text
每格读：
L = slot[j]，U = slot[j+1]

处理后写：
D = slot[j]，R = slot[j+1]

00 -> 建 D,R，形成 ()
单插头 -> 延伸到 D 或 R
11 -> 向右找匹配 2，把它改成 1
22 -> 向左找匹配 1，把它改成 2
21 -> 直接合并
12 -> 闭环，只允许最后一个可走格且无其他插头

每行结束：state <<= 2
```

## 10.9 SOS DP（子集 / 超集和）

> **用途**：对所有 `mask` 同时求其所有子集或所有超集的权值和，并支持 Möbius 逆变换。
> **复杂度**：时间 `O(n2^n)`，空间 `O(2^n)`
> **下标**：二进制位 `0 ~ n-1`

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

void sosSubset(vector<ll>& f, int n) {
    int S = 1 << n;

    for (int i = 0; i < n; ++i)
        for (int mask = 0; mask < S; ++mask)
            if (mask >> i & 1)
                f[mask] += f[mask ^ (1 << i)];
}

void mobiusSubset(vector<ll>& f, int n) {
    int S = 1 << n;

    for (int i = 0; i < n; ++i)
        for (int mask = 0; mask < S; ++mask)
            if (mask >> i & 1)
                f[mask] -= f[mask ^ (1 << i)];
}

void sosSuperset(vector<ll>& f, int n) {
    int S = 1 << n;

    for (int i = 0; i < n; ++i)
        for (int mask = 0; mask < S; ++mask)
            if (!(mask >> i & 1))
                f[mask] += f[mask | (1 << i)];
}

void mobiusSuperset(vector<ll>& f, int n) {
    int S = 1 << n;

    for (int i = 0; i < n; ++i)
        for (int mask = 0; mask < S; ++mask)
            if (!(mask >> i & 1))
                f[mask] -= f[mask | (1 << i)];
}
```

### 现场记忆

```text
子集和：
mask 有第 i 位
f[mask] += f[mask ^ (1<<i)]

超集和：
mask 没第 i 位
f[mask] += f[mask | (1<<i)]

Möbius 逆变换：把 += 改成 -=
```

## 10.10 单调队列优化 DP

> **用途**：优化形如 `dp[i] = A[i] + min/max F(j)`，且合法决策 `j` 位于滑动窗口中的转移。
> **复杂度**：时间 `O(n)`，空间 `O(n)`
> **下标**：`1-indexed`
> **限制**：代码对应 `dp[i] = a[i] + min(dp[j])`，其中 `i-k <= j < i`，`k >= 1`。

```cpp
const ll INF = LLONG_MAX / 4;

vector<ll> a(n + 1), dp(n + 1, INF);
for (int i = 1; i <= n; ++i) cin >> a[i];

deque<int> q;
dp[0] = 0;
q.push_back(0);

for (int i = 1; i <= n; ++i) {
    while (!q.empty() && q.front() < i - k) q.pop_front();

    dp[i] = dp[q.front()] + a[i];

    while (!q.empty() && dp[q.back()] >= dp[i]) q.pop_back();
    q.push_back(i);
}

cout << dp[n] << '\n';
```

### 现场记忆

```text
先把转移整理成：dp[i] = A[i] + min/max F(j)

队首：当前最优决策
队尾：删掉以后永远不可能更优的决策

过期：j < i-k -> pop_front()
维护最小值：F(back) >= F(i) -> pop_back()
维护最大值时反转比较符号
```

## 10.11 斜率优化 CHT

> **用途**：优化形如 `dp[i] = A[i] + min_j(k[j] * x[i] + b[j])` 的线性转移。
> **复杂度**：每条直线均摊 `O(1)` 加入、查询，总时间 `O(n)`，空间 `O(n)`
> **下标**：按原 DP 自然决定
> **限制**：直线斜率 `k` 按加入顺序单调不增，查询 `x` 单调不减。
> **注意**：乘法和交点判断使用 `__int128` 防溢出；若斜率或查询顺序不单调，改用 Li Chao Tree。

### 调用

```cpp
vector<ll> dp(n + 1);

CHTMin cht;
cht.add(k[0], dp[0]);

for (int i = 1; i <= n; ++i) {
    dp[i] = A[i] + cht.query(x[i]);
    cht.add(k[i], dp[i]);
}
```

### 接口速查

| 接口 | 含义 |
|---|---|
| `add(k, b)` | 加入直线 `y = kx + b` |
| `query(x)` | 查询所有直线在 `x` 处的最小值 |

### 模板

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;
using i128 = __int128_t;

struct CHTMin {
    struct Line {
        ll k, b;
    };

    deque<Line> q;

    i128 eval(const Line& l, ll x) {
        return (i128)l.k * x + l.b;
    }

    bool bad(const Line& a, const Line& b, const Line& c) {
        return ((i128)b.b - a.b) * ((i128)b.k - c.k) >= ((i128)c.b - b.b) * ((i128)a.k - b.k);
    }

    void add(ll k, ll b) {
        Line c{k, b};

        while (!q.empty() && q.back().k == k) {
            if (q.back().b <= b) return;
            q.pop_back();
        }

        while (q.size() >= 2 && bad(q[q.size() - 2], q.back(), c)) q.pop_back();
        q.push_back(c);
    }

    ll query(ll x) {
        while (q.size() >= 2 && eval(q[0], x) >= eval(q[1], x)) q.pop_front();
        return (ll)eval(q[0], x);
    }
};
```

### 现场记忆

```text
先把 DP 化成：
dp[i] = A[i] + min(k[j] * x[i] + b[j])

一个决策 j -> 一条直线 y = kx + b。

斜率单调 -> 插入时弹掉无用直线。
x 单调 -> 查询时不断弹队首。

三线 a,b,c：
intersection(a,b) >= intersection(b,c) -> b 永远无用。

非单调查询 / 非单调斜率 -> Li Chao Tree。
```

## 10.12 分治优化 DP

> **用途**：优化分段 DP：`dp[t][i] = min_{j<i}(dp[t-1][j] + cost(j+1,i))`。
> **复杂度**：若 `cost` 为 `O(1)`，时间通常由 `O(Kn^2)` 优化到 `O(Kn log n)`，空间 `O(n)`
> **下标**：位置 `1 ~ n`，前驱位置 `0 ~ n-1`
> **限制**：必须满足最优决策单调：`opt[t][i] <= opt[t][i+1]`。
> **注意**：决策单调性不是代码自动保证的，必须由题目性质 / Monge 性质 / 四边形不等式等证明。

### 调用

```cpp
vector<ll> preSum(n + 1);
for (int i = 1; i <= n; ++i) preSum[i] = preSum[i - 1] + a[i];

auto cost = [&](int l, int r) -> ll {
    ll s = preSum[r] - preSum[l - 1];
    return s * s;
};

auto dp = divideConquerDP(n, K, cost);
cout << dp[n] << '\n';
```

### 模板

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

template<class F>
vector<ll> divideConquerDP(int n, int K, F cost) {
    const ll INF = LLONG_MAX / 4;

    vector<ll> pre(n + 1, INF), cur(n + 1, INF);
    pre[0] = 0;

    for (int t = 1; t <= K; ++t) {
        fill(cur.begin(), cur.end(), INF);

        auto solve = [&](auto&& self, int l, int r, int optL, int optR) -> void {
            if (l > r) return;

            int mid = (l + r) >> 1;
            ll best = INF;
            int bestPos = -1;
            int R = min(mid - 1, optR);

            for (int j = optL; j <= R; ++j) {
                if (pre[j] >= INF / 2) continue;

                ll val = pre[j] + cost(j + 1, mid);
                if (val < best) {
                    best = val;
                    bestPos = j;
                }
            }

            cur[mid] = best;

            if (l == r) return;
            self(self, l, mid - 1, optL, bestPos);
            self(self, mid + 1, r, bestPos, optR);
        };

        if (t <= n) solve(solve, t, n, t - 1, n - 1);
        pre.swap(cur);
    }

    return pre;
}
```

### 现场记忆

```text
原转移：
dp[t][i] = min(dp[t-1][j] + cost(j+1,i))

核心条件：
opt[t][i] <= opt[t][i+1]

算 mid 时只搜 [optL, optR]。
得到最优 bestPos 后：

左半边决策范围  [optL, bestPos]
右半边决策范围  [bestPos, optR]

不要看到“分段 DP”就直接套，先确认决策单调。
```

## 10.13 Knuth 优化（区间 DP）

> **用途**：将满足 Knuth 决策单调条件的区间 DP 从 `O(n^3)` 优化到 `O(n^2)`；代码对应相邻石子合并最小代价。
> **复杂度**：时间 `O(n^2)`，空间 `O(n^2)`
> **下标**：`1-indexed`
> **限制**：经典石子合并版本要求权值非负。
> **注意**：必须满足 `opt[l][r-1] <= opt[l][r] <= opt[l+1][r]`，不能只因为形式像区间 DP 就套。

```cpp
const ll INF = LLONG_MAX / 4;

vector<ll> a(n + 1), pre(n + 1);
for (int i = 1; i <= n; ++i) {
    cin >> a[i];
    pre[i] = pre[i - 1] + a[i];
}

vector<vector<ll>> dp(n + 2, vector<ll>(n + 2));
vector<vector<int>> opt(n + 2, vector<int>(n + 2));

for (int i = 1; i <= n; ++i) opt[i][i] = i;

for (int len = 2; len <= n; ++len) {
    for (int l = 1; l + len - 1 <= n; ++l) {
        int r = l + len - 1;
        dp[l][r] = INF;

        int L = opt[l][r - 1];
        int R = min(opt[l + 1][r], r - 1);

        for (int k = L; k <= R; ++k) {
            ll val = dp[l][k] + dp[k + 1][r];

            if (val < dp[l][r]) {
                dp[l][r] = val;
                opt[l][r] = k;
            }
        }

        dp[l][r] += pre[r] - pre[l - 1];
    }
}

cout << dp[1][n] << '\n';
```

### 现场记忆

```text
普通区间 DP：枚举 l,r，再枚举全部 k -> O(n^3)

Knuth 只搜：
opt[l][r-1] <= k <= opt[l+1][r]

即：
opt[l][r-1] <= opt[l][r] <= opt[l+1][r]

石子合并：
dp[l][r] = min(dp[l][k] + dp[k+1][r]) + sum(l,r)
```

## 10.14 Li Chao Tree 优化 DP

> **用途**：维护若干直线 `y = kx + b` 的最小值，处理斜率、查询 `x` 均不保证单调的线性 DP。
> **复杂度**：单次插入 / 查询 `O(log |R-L|)`，空间 `O(q log |R-L|)`
> **下标**：查询坐标为整数 `x ∈ [L,R]`
> **限制**：代码维护最小值；实际答案需能放入 `long long`。
> **注意**：若斜率和查询都满足单调性，优先用单调 CHT，常数更小。

### 调用

```cpp
LiChaoMin cht(-1000000000LL, 1000000000LL);

cht.add(k, b);
cout << cht.query(x) << '\n';
```

### 接口速查

| 接口 | 含义 |
|---|---|
| `LiChaoMin(L,R)` | 初始化查询坐标范围 |
| `add(k,b)` | 加入直线 `y = kx + b` |
| `query(x)` | 查询所有直线在 `x` 处的最小值 |

### 模板

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;
using i128 = __int128_t;

struct LiChaoMin {
    static constexpr ll INF = 1LL << 62;

    struct Line {
        ll k = 0, b = 0;

        i128 eval(ll x) const {
            return (i128)k * x + b;
        }
    };

    struct Node {
        Line line;
        int ls = 0, rs = 0;
        bool has = false;
    };

    ll L, R;
    vector<Node> tr;

    LiChaoMin(ll L_, ll R_) : L(L_), R(R_) {
        tr.resize(2);
    }

    int newNode() {
        tr.push_back({});
        return (int)tr.size() - 1;
    }

    void add(Line nw, int p, ll l, ll r) {
        if (!tr[p].has) {
            tr[p].line = nw;
            tr[p].has = true;
            return;
        }

        if (tr[p].line.k == nw.k) {
            if (nw.b < tr[p].line.b) tr[p].line = nw;
            return;
        }

        ll mid = l + (r - l) / 2;
        bool lef = nw.eval(l) < tr[p].line.eval(l);
        bool midBetter = nw.eval(mid) < tr[p].line.eval(mid);

        if (midBetter) swap(nw, tr[p].line);
        if (l == r) return;

        if (lef != midBetter) {
            if (!tr[p].ls) tr[p].ls = newNode();
            add(nw, tr[p].ls, l, mid);
        } else {
            if (!tr[p].rs) tr[p].rs = newNode();
            add(nw, tr[p].rs, mid + 1, r);
        }
    }

    void add(ll k, ll b) {
        add({k, b}, 1, L, R);
    }

    i128 query128(ll x, int p, ll l, ll r) const {
        const i128 IINF = (i128)1 << 120;

        i128 res = tr[p].has ? tr[p].line.eval(x) : IINF;
        if (l == r) return res;

        ll mid = l + (r - l) / 2;

        if (x <= mid && tr[p].ls) res = min(res, query128(x, tr[p].ls, l, mid));
        if (x > mid && tr[p].rs) res = min(res, query128(x, tr[p].rs, mid + 1, r));

        return res;
    }

    ll query(ll x) const {
        i128 res = query128(x, 1, L, R);

        if (res >= (i128)INF) return INF;
        if (res <= -(i128)INF) return -INF;
        return (ll)res;
    }
};
```

### 现场记忆

```text
目标先化成：
dp[i] = A[i] + min(k[j] * x[i] + b[j])

Li Chao：每个线段树节点保留“中点更优”的那条线。
剩下那条线只可能在左半或右半继续有用。

斜率 / x 不单调 -> Li Chao
二者单调 -> 优先单调 CHT

求最大值：把 k、b 取反，最后答案再取反。
```

## 10.15 Bitset 优化 DP（0/1 子集和）

> **用途**：快速求若干非负整数能组成哪些和，是布尔 0/1 背包的高效写法。
> **复杂度**：时间约 `O(nC / 64)`，空间 `O(C)`
> **下标**：`dp[s] = 1` 表示和 `s` 可达
> **限制**：`MAXC` 为编译期常量，物品权值非负。

```cpp
const int MAXC = 200000;

bitset<MAXC + 1> dp;
dp[0] = 1;

for (int i = 1; i <= n; ++i) {
    int w;

}

cout << dp[x] << '\n';
```

### 现场记忆

```text
普通 0/1 布尔背包：dp[j] |= dp[j-w]
bitset：dp |= dp << w
```

## 10.16 WQS 二分 / Aliens Trick

> **用途**：将“恰好选 `K` 个 / 分成 `K` 段”的 DP，转化为给每次选择增加惩罚 `lambda` 的一维 DP。
> **复杂度**：`O(Tcheck log V)`；代码骨架中 `check` 为 `O(n^2)`，总计 `O(n^2 log V)`
> **下标**：位置 `1 ~ n`
> **限制**：最优代价关于选择次数需满足离散凸性，使选择次数随 `lambda` 单调。
> **注意**：最小化问题中每段增加 `+lambda`；同代价时必须优先选择更多段。

```cpp
struct State {
    ll val;
    int cnt;
};

auto better = [&](const State& a, const State& b) {
    if (a.val != b.val) return a.val < b.val;
    return a.cnt > b.cnt;
};

auto check = [&](ll lambda) {
    const ll INF = 1LL << 62;

    vector<State> dp(n + 1, {INF, -1000000000});
    dp[0] = {0, 0};

    for (int i = 1; i <= n; ++i) {
        for (int j = 0; j < i; ++j) {
            if (dp[j].val >= INF / 2) continue;

            State cur{
                dp[j].val + cost(j + 1, i) + lambda,
                dp[j].cnt + 1
            };

            if (better(cur, dp[i])) dp[i] = cur;
        }
    }

    return dp[n];
};

ll lo = -LIM, hi = LIM;

while (lo < hi) {
    ll mid = lo + (hi - lo + 1) / 2;

    if (check(mid).cnt >= K) lo = mid;
    else hi = mid - 1;
}

State res = check(lo);
ll ans = res.val - lo * K;

cout << ans << '\n';
```

### 现场记忆

```text
原问题：恰好选 K 次
加入惩罚：new_cost = old_cost + lambda * cnt

lambda 越大 -> 越不愿意多选 -> cnt 单调不增

最小化：
同 penalized cost 时优先 cnt 更多
二分最大的 lambda，使 cnt >= K

答案：F(lambda) - lambda*K
check() 仍可继续用 CHT / 分治等优化
```


## CDQ 优化三维偏序 DP

> **用途**：求三维偏序下的最长 / 最大权链，转移形如  
> `dp[i] = max(dp[i], dp[j] + w[i])`，其中 `j` 在三个维度上均满足对应的 `<` 或 `<=`。
>
> **复杂度**：时间 `O(n log^2 n)`，空间 `O(n)`
>
> **下标**：点 `1-indexed`
>
> **注意**：
> 1. `STRICT_X / STRICT_Y / STRICT_Z = true` 表示该维必须严格 `<`，`false` 表示允许 `<=`。
> 2. 第一维是否允许取等，影响的是 **CDQ 分治边界**；第二维影响 **扫描加入条件**；第三维影响 **BIT 查询位置**。
> 3. 若三个维度全部允许 `<=`，完全相同的点也可以依次转移；模板使用 `id` 打破完全相同点的顺序。

### 调用

```cpp
constexpr bool STRICT_X = true;   // x[j] <  x[i]
constexpr bool STRICT_Y = false;  // y[j] <= y[i]
constexpr bool STRICT_Z = true;   // z[j] <  z[i]

// 输入：x y z w
// dp[i] = 以当前点结尾的最大权值
// 最终输出最长 / 最大权链
```

如果是普通最长链，每个点权值直接令：

```cpp
w = 1;
```

例如要求：

```text
x[j] <= x[i]
y[j] <  y[i]
z[j] <= z[i]
```

则：

```cpp
STRICT_X = false;
STRICT_Y = true;
STRICT_Z = false;
```

### 三维取等速查

| 第一维 | 第二维 | 第三维 | `STRICT_X` | `STRICT_Y` | `STRICT_Z` |
|---|---|---|---|---|---|
| `<` | `<` | `<` | `true` | `true` | `true` |
| `<` | `<` | `<=` | `true` | `true` | `false` |
| `<` | `<=` | `<` | `true` | `false` | `true` |
| `<` | `<=` | `<=` | `true` | `false` | `false` |
| `<=` | `<` | `<` | `false` | `true` | `true` |
| `<=` | `<` | `<=` | `false` | `true` | `false` |
| `<=` | `<=` | `<` | `false` | `false` | `true` |
| `<=` | `<=` | `<=` | `false` | `false` | `false` |

### 模板

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

const ll NEG = -(1LL << 60);

// true : 严格 <
// false: 允许 <=
constexpr bool STRICT_X = true;
constexpr bool STRICT_Y = true;
constexpr bool STRICT_Z = true;

struct Node {
    ll x, y, z;
    ll w, dp;
    int id, rz;
};

struct BIT {
    int n;
    vector<ll> t;
    vector<int> touched;

    void init(int n_) {
        n = n_;
        t.assign(n + 1, NEG);
        touched.clear();
    }

    void modify(int x, ll v) {
        for (; x <= n; x += x & -x) {
            if (t[x] == NEG) touched.push_back(x);
            t[x] = max(t[x], v);
        }
    }

    ll query(int x) {
        ll res = NEG;
        for (; x > 0; x -= x & -x)
            res = max(res, t[x]);
        return res;
    }

    void clear() {
        for (int x : touched)
            t[x] = NEG;
        touched.clear();
    }
};

int n;
vector<Node> a;
BIT bit;

void trans(int l, int mid, int r) {
    vector<int> L, R;

    for (int i = l; i <= mid; ++i)
        L.push_back(i);

    for (int i = mid + 1; i <= r; ++i)
        R.push_back(i);

    auto cmp_y = [&](int i, int j) {
        if (a[i].y != a[j].y)
            return a[i].y < a[j].y;
        if (a[i].z != a[j].z)
            return a[i].z < a[j].z;
        return i < j;
    };

    sort(L.begin(), L.end(), cmp_y);
    sort(R.begin(), R.end(), cmp_y);

    int p = 0;

    for (int v : R) {
        // 第二维：
        // strict    -> y[left] <  y[right]
        // nonstrict -> y[left] <= y[right]
        while (
            p < (int)L.size() &&
            (STRICT_Y
                ? a[L[p]].y < a[v].y
                : a[L[p]].y <= a[v].y)
        ) {
            bit.modify(a[L[p]].rz, a[L[p]].dp);
            ++p;
        }

        // 第三维：
        // strict    -> query(rz - 1)
        // nonstrict -> query(rz)
        int q = a[v].rz - (STRICT_Z ? 1 : 0);

        ll best = bit.query(q);

        if (best != NEG)
            a[v].dp = max(a[v].dp, best + a[v].w);
    }

    bit.clear();
}

void cdq(int l, int r) {
    if (l >= r) return;

    int mid = (l + r) >> 1;

    if constexpr (STRICT_X) {
        /*
        第一维严格 < 时：
        不能让相同 x 被 CDQ 切到左右两边，
        否则会错误产生 x[left] == x[right] 的转移。
        */

        int rr = mid;

        while (
            rr < r &&
            a[rr + 1].x == a[mid].x
        )
            ++rr;

        if (rr < r) {
            mid = rr;
        } else {
            int ll = mid;

            while (
                ll > l &&
                a[ll - 1].x == a[mid].x
            )
                --ll;

            // 整段 x 完全相同，不存在严格 x 转移
            if (ll == l)
                return;

            mid = ll - 1;
        }
    }

    cdq(l, mid);

    // 左半部分 dp 已经求完，用它更新右半部分
    trans(l, mid, r);

    cdq(mid + 1, r);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;

    a.resize(n + 1);

    for (int i = 1; i <= n; ++i) {
        cin >> a[i].x
            >> a[i].y
            >> a[i].z
            >> a[i].w;

        a[i].id = i;
    }

    /*
    第一维排序。

    x 允许 <= 时，相同 x 内按照 y,z,id 排序，
    给相等第一维的状态确定合法转移顺序。
    */
    sort(
        a.begin() + 1,
        a.end(),
        [](const Node &A, const Node &B) {
            if (A.x != B.x) return A.x < B.x;
            if (A.y != B.y) return A.y < B.y;
            if (A.z != B.z) return A.z < B.z;
            return A.id < B.id;
        }
    );

    vector<ll> zs;

    for (int i = 1; i <= n; ++i)
        zs.push_back(a[i].z);

    sort(zs.begin(), zs.end());

    zs.erase(
        unique(zs.begin(), zs.end()),
        zs.end()
    );

    for (int i = 1; i <= n; ++i) {
        a[i].rz =
            lower_bound(
                zs.begin(),
                zs.end(),
                a[i].z
            ) - zs.begin() + 1;

        a[i].dp = a[i].w;
    }

    bit.init(zs.size());

    cdq(1, n);

    ll ans = NEG;

    for (int i = 1; i <= n; ++i)
        ans = max(ans, a[i].dp);

    cout << ans << '\n';

    return 0;
}
```

### `< / <=` 到底改哪里

三个维度分别对应三处，比赛现场只记这三句话。

#### 第一维 `x`

要求：

```text
x[j] < x[i]
```

则：

```cpp
STRICT_X = true;
```

CDQ 必须保证：

```text
左半所有 x < 右半所有 x
```

所以 **相同 `x` 不能被分到 CDQ 左右两边**。

要求：

```text
x[j] <= x[i]
```

则：

```cpp
STRICT_X = false;
```

普通：

```cpp
mid = (l + r) >> 1;
```

即可，相同 `x` 可以发生左 → 右转移。

---

#### 第二维 `y`

严格：

```text
y[j] < y[i]
```

扫描条件：

```cpp
a[L[p]].y < a[v].y
```

即：

```cpp
STRICT_Y = true;
```

可取等：

```text
y[j] <= y[i]
```

扫描条件：

```cpp
a[L[p]].y <= a[v].y
```

即：

```cpp
STRICT_Y = false;
```

---

#### 第三维 `z`

严格：

```text
z[j] < z[i]
```

只能查询比当前 `z` 小的值：

```cpp
bit.query(rz - 1);
```

即：

```cpp
STRICT_Z = true;
```

可取等：

```text
z[j] <= z[i]
```

当前 `z` 本身也可以作为前驱：

```cpp
bit.query(rz);
```

即：

```cpp
STRICT_Z = false;
```

### 现场记忆

```text
三维偏序：

第 1 维 x：
    <  -> CDQ 不能切开相同 x
    <= -> 普通 CDQ 分治

第 2 维 y：
    <  -> 加入 left.y < right.y
    <= -> 加入 left.y <= right.y

第 3 维 z：
    <  -> BIT.query(rk - 1)
    <= -> BIT.query(rk)

记忆：
第一维看“分治边界”
第二维看“什么时候加入 BIT”
第三维看“BIT 查到哪里”
```

### 常见改法

如果求最长链：

```cpp
a[i].w = 1;
```

转移就是：

```cpp
dp[i] = max(dp[i], dp[j] + 1);
```

如果题目是：

```text
x[j] <  x[i]
y[j] <= y[i]
z[j] <  z[i]
```

直接：

```cpp
STRICT_X = true;
STRICT_Y = false;
STRICT_Z = true;
```

如果题目是：

```text
x[j] <= x[i]
y[j] <= y[i]
z[j] <= z[i]
```

直接：

```cpp
STRICT_X = false;
STRICT_Y = false;
STRICT_Z = false;
```
